# Demo (15 min)
1. Problem (1 min): knowledge is scattered; people ask the same questions; NDAs make sharing risky.
2. Happy path (3 min): ask 2 real questions; show answer, citations, last-updated, outdated warning.
3. Honesty (2 min): ask something undocumented; show "not found" instead of a guess.
4. Safety (3 min): switch simulated user to new_nina and ask about Project Alpha: nothing leaks. Show the audit log row.
5. Numbers (3 min): results table (hit@5, correctness, citations, not-found, access tests 100%); variant comparison.
6. Pilot (2 min): usage, ratings, repeat users, top unanswered questions (documentation gaps).
7. Ask (1 min): next phase, cost estimate, the buy-vs-build recommendation.
